# Diffusion-Based Lunar Crater Detection and Classification using U-Net

## Project Abstract
The lunar surface is densely populated with craters of varying sizes... (Abstract Content)

## Architecture
- **Diffusion-inspired Preprocessing**: Anisotropic diffusion and CLAHE enhancement.
- **Segmentation**: U-Net Architecture (4 level encoder-decoder with skip connections).
- **Classification**: Geometrical morphology analysis for Small, Medium, and Large craters.
